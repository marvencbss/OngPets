# OngPets

Sistema web para cadastro e gerenciamento de cães e gatos perdidos e encontrados na região de São Leopoldo, RS.

## Tecnologias

- Java 17
- Spring Boot 3.2
- Thymeleaf
- Bootstrap 5
- Maven

## Como rodar

1. Clone o repositório
2. Abra o projeto no Eclipse como **Maven Project**
3. Execute a classe `Main.java` como **Java Application**
4. Acesse no navegador: `http://localhost:8080`

## Rotas principais


| `/`  Página inicial 
| `/animais`  Lista de animais 
| `/animais/novo`  Cadastrar pet 
| `/api/animais`  API REST
